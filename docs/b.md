# Exercise 2

Each program that runs on your computer has a process associated with it that starts the program. You can use Task Manager to see the processes that are currently running on your computer. You can review CPU and memory usage. Use ALT-CTRL-DEL to open Task Manager.

1. Click the Processes tab. This shows a list of application programs currently running.
2. Click on the Performance tab, examine the information available and explain what you are seeing. Click on Open Resource Monitor, again review and understand what is available. There is a lot of detail, you may find yourself researching to find out what everything means.
3. Click the Services tab to see the services that are currently running under your user account.
